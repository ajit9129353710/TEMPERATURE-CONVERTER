 Temperature Converter

A simple and interactive temperature converter web app built using HTML, CSS, and JavaScript.

 Features

- Convert temperature between:
  - Celsius to Fahrenheit & Kelvin
  - Fahrenheit to Celsius & Kelvin
- Real-time calculation
- Clean and simple UI
- Beginner-friendly project

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

 Project Structure

TEMPERATURE-CONVERTER/
│── index.html
│── script.js
│── style.css

 How to Run

1. Download or clone the repository
2. Open "index.html" in your browser
3. Enter temperature value
4. Select unit (Celsius/Fahrenheit)
5. Get instant result

📸 Output

Displays converted temperature values with proper formatting.

 Example

- Input: 25°C
- Output:
  - Fahrenheit: 77°F
  - Kelvin: 298K

 Purpose

This project is made for practice and improving JavaScript concepts like:

- DOM Manipulation
- Event Handling
- Conditional Logic
